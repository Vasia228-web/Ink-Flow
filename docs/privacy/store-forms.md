# SpacePaint — дані для політики й форм магазинів (чернетка, 2026-10-24)

> **Не юридична консультація.** Це чернетка, складена за кодом гри й планом першої версії. Перед публікацією автор перевіряє позначене ⚠ сам: з документацією Google, Apple й Unity (їхні вимоги змінюються), а за потреби — з юристом.

Файли:
- `docs/privacy/index.html` — політика українською й англійською (одна сторінка). Розміщення: будь-який хостинг зі сталою адресою https. GitHub Pages із теки `docs/` безкоштовний лише для **публічного** репозиторію; для приватного — окремий публічний репозиторій лише з цим файлом або інший хостинг.
- Після розміщення адреса політики йде в `AppConfig` → `privacyPolicyUrl`, пошта — у `supportEmail`; до того в налаштуваннях гри «Політика» й «Підтримка» показують «Скоро».

## Що автор має заповнити й вирішити сам

1. **Пошта** замість `[ПОШТА]` / `[EMAIL]` — та сама в політиці, у `AppConfig.supportEmail`, у Play Console й App Store Connect. Раджу окрему скриньку для гри.
2. **Ім'я або назва розробника** замість `[ІМ'Я АБО НАЗВА РОЗРОБНИКА]` / `[DEVELOPER NAME]` — так само, як в акаунтах розробника.
3. ⚠ **Рекламна мережа.** Політика припускає Unity Ads через Unity LevelPlay (вибір — у промті «Перша версія»). Інша мережа (наприклад, AdMob) — заміни назву й посилання на її політику в обох мовах і перевір її список даних.
4. ⚠ **Вік — 13+, гра не для дітей** (рішення 3А). У Play Console: цільова аудиторія 13+, «Не приваблює дітей». В App Store — вікова категорія за анкетою (очікувано 4+ за змістом, але це про зміст, а не про аудиторію). Опис і скріни не подають гру як дитячу (п. 10 «Дороги»).
5. ⚠ **Термін «30 днів» на видалення** — реальний для тебе? Якщо ні — постав свій.
6. ⚠ **Що публічне.** Інші гравці бачать нік, аватар (набір або картинку з колекції), планети, галактики, рекорд і галактику з картинками. Профіль можна сховати. Якщо щось із цього не хочеш робити публічним — скажи, приберу з гри й з політики.

## Які дані гра обробляє (за кодом, 2026-10-24)

| Дані | Звідки | Куди | Публічно? |
|---|---|---|---|
| Прогрес (колекція, галактики, нафта, налаштування, рекорд) | гра | лише файл на пристрої (`persistentDataPath/save.json`) | ні |
| Анонімний ідентифікатор гравця | UGS Authentication (анонімний вхід) | Unity | ні |
| Нік, аватар (номер набору або назва картинки), планети, галактики, рекорд, прапорець інкогніто | `RankingsSync` → UGS Leaderboards, таблиця `planets_all` (метадані запису) | Unity | так (інкогніто — лише числа) |
| Публічна вітрина: нік, аватар, слоти показуваної галактики, вітринна картинка, лічильники | `RankingsSync` → UGS Cloud Save, ключ `showcase`, публічне читання | Unity | так (інкогніто — лише лічильники) |
| Рекламний ID (лише з дозволом / згодою), IP, модель пристрою, ОС, взаємодія з рекламою | рекламний SDK (ще не встановлено) | рекламна мережа | ні |

**Чого немає:** аналітики (у першій версії її немає; вбудований модуль Unity Analytics вимкнено в `UnityConnectSettings`), звітів про збої Unity Cloud Diagnostics (вимкнено), місцезнаходження, контактів, фото, камери, мікрофона, покупок (магазин нафти — у запасі).

⚠ Перевірити перед поданням: `UgsServices.cs` пише вітрину з `PublicWriteAccessClassOptions` — за документацією Cloud Save це «публічне читання, запис лише власником»; підтвердити, коли пакети буде встановлено (адаптер ще не компілювався).

## Google Play — «Data safety» (чернетка відповідей)

- **Чи збирає або передає застосунок дані користувачів?** Так.
- **Чи всі дані шифруються під час передавання?** Так (HTTPS у UGS і рекламного SDK).
- **Чи можна попросити видалити дані?** Так — через пошту (посилання на політику з розділом «Як видалити»).
- **Дані, які збираються:**

| Категорія → тип | Збирається | Передається третім сторонам | Обов'язково? | Навіщо |
|---|---|---|---|---|
| Personal info → User IDs (анонімний ID гравця) | так | ні (Unity — постачальник послуг) ⚠ | так | App functionality (рейтинги) |
| Personal info → Name (нік у грі) ⚠ — Google може вважати ігровий нік «іменем» | так | ні | ні (можна лишити «Гравець») | App functionality |
| App activity → Other user-generated content (галактика з картинками, аватар-картинка) | так | ні | ні | App functionality |
| App activity → Other actions (рекорд, кількість планет і галактик) ⚠ | так | ні | так | App functionality |
| Device or other IDs → Advertising ID | так (рекламний SDK) | так — рекламна мережа | так ⚠ (якщо SDK збирає без згоди — перевір його форму) | Advertising or marketing |
| App info and performance → Crash logs / Diagnostics ⚠ | лише якщо їх збирає рекламний SDK | ⚠ | — | Analytics (SDK) |

- ⚠ Рекламні SDK публікують власні «Data safety» підказки (Unity LevelPlay — так) — звір із ними, вони мають пріоритет.
- Цільова аудиторія (окрема анкета): 13+; «Чи може застосунок ненавмисно привабити дітей?» — ні (див. п. 4 вище).

## Apple — «App Privacy» (чернетка відповідей)

- **Data Used to Track You:** Identifiers → Device ID (IDFA) — лише після дозволу ATT; мета — Third-Party Advertising. ⚠ Якщо обіцяти, що без ATT нічого не йде, у SDK має бути увімкнено відповідний режим.
- **Data Linked to You:**
  - Identifiers → User ID (анонімний ID UGS) — App Functionality.
  - User Content → Other User Content (нік, галактика з картинками, аватар) — App Functionality. ⚠
  - Usage Data → Product Interaction / Advertising Data (взаємодія з рекламою) — Third-Party Advertising (з рекламного SDK). ⚠
- **Data Not Linked to You:** Diagnostics → Crash Data — лише якщо збирає рекламний SDK ⚠.
- **Privacy Policy URL:** адреса розміщеного `index.html`.
- ⚠ Потрібен `PrivacyInfo.xcprivacy` (маніфест приватності) — він іде разом із SDK (Unity, LevelPlay) і застосунку; п. 10 «Дороги».
- ⚠ `NSUserTrackingUsageDescription` (текст запиту ATT) — додається разом із рекламою (п. 7 «Дороги»). Чернетка: «Дозволь — і реклама буде цікавішою. Без дозволу гра працює так само.» / "Allow to see more relevant ads. The game works the same either way."
