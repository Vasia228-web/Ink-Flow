# W4DarkCanvas — картинка на темному полотні

![preview](preview_W4DarkCanvas.png)

## Ідея

Картинка — той самий піксель-арт, **пікселі завжди рівні й квадратні** (жодних викривлень). Вона лежить на темному синьо-фіолетовому полотні в тон гри. Стиль додає лише фактуру плетіння, м'яке світло зверху, тінь знизу і гало навколо. Незафарбована частина — тонкі світлі контури.

Цей стиль **замінює P2Watercolor**. Акварель більше не використовується.

## Шари (знизу вгору)

| Шар | Файл | Що це | Коли видно |
| --- | --- | --- | --- |
| 1 | `_canvas` | темне полотно з плетінням | завжди |
| 2 | `_sketch` | світлі контури всіх кольорових зон | завжди (фарба його перекриває) |
| 3 | `_halo` | м'яке кольорове світіння | тільки навколо зафарбованих пікселів |
| 4 | `_paint` | готова картинка: рівні пікселі + світло/тінь + плетіння | тільки зафарбовані пікселі |

Усі шари однакового розміру: `(ширина_арту + 2·margin) × px` на `(висота_арту + 2·margin) × px`.

## Як запекти шари для картинки

```
pip install pillow numpy scipy
python tools/darkcanvas.py rogatyk.png --px 16 --margin 2 --out Baked/
```

- `--px` — пікселів текстури на один піксель арту. Для арту ~32 px підходить 16 (текстура 576×576).
- `--margin` — порожнє полотно навколо малюнка, у пікселях арту.
- Скрипт також робить `_preview_empty.png` і `_preview_done.png`, щоб перевірити результат на око.

## Як показувати прогрес у грі

- Маска прогресу має розмір арту (наприклад, 32×32), фільтр **Point**: 1 — піксель зафарбовано, 0 — ні.
- Шар `_paint` показується тільки там, де маска = 1. Край пікселя лишається різким.
- Шар `_halo` бере ту саму маску, але з фільтром Bilinear, тому світіння наростає м'яко.
- Появу пікселя можна анімувати: 0 → 1 за 0.15–0.25 с плюс легкий «поп» масштабу.

## Параметри (усі в `CFG` у скрипті, у грі — в конфіг)

| Параметр | Значення | Що робить |
| --- | --- | --- |
| полотно | `#403c78` | колір полотна |
| weave_pitch | 0.25 пікселя арту | розмір клітинки плетіння |
| weave_alpha | 0.045 | сила плетіння на полотні |
| weave_on_paint | 0.6 | скільки плетіння видно крізь фарбу |
| light_top / shade_bottom | 0.16 / 0.16 | світло зверху / тінь знизу |
| halo_sigma / halo_alpha | 1.4 пікселя арту / 0.45 | розмір і сила гало |
| sketch колір / alpha | `#dfe0f5` / 0.35 | контури незафарбованої частини |

## Рамка

Полотно лежить усередині панелі K1Candy з кутами 16 px (на полотні) і тонкою темною рамкою 35%. Рамка рідкості (наприклад, зелена) — на самій панелі, товщина 3 px.

## Обмеження

- **Без Post-process Bloom.** Гало — це запечена текстура `_halo`.
- Контур картинки має бути темнішим або світлішим за полотно `#403c78`. Дуже темні контури (наприклад, `#2b2440`) видно добре. Контур, близький за кольором до полотна, зникне — перевір по `_preview_done.png`.
