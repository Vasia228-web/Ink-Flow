# Ink Flow — стиль картинки W4DarkCanvas

- **SPEC.md** — як виглядає стиль, які є шари, параметри і як показувати прогрес.
- **preview_W4DarkCanvas.png** — еталон: порожня картинка, картинка в процесі, готова.
- **tools/darkcanvas.py** — запікає шари для будь-якої піксельної картинки.
- **example/** — тестовий рогатик 32×32 і всі його шари.
- **textures/canvas_weave_tile_64.png** — безшовне полотно, якщо фон треба розтягнути.

Цей стиль замінює акварельний; його еталони з `docs/StyleRef/` прибрано, щоб не було двох правд.
