# P2Watercolor — картинка аквареллю на папері

![preview](preview_P2Watercolor.png)

## Ідея

Картинка — той самий піксель-арт, але показана як акварель на теплому папері. Незафарбована частина — олівцевий ескіз. Коли гравець заповнює зону, вона плавно «проявляється» аквареллю.

## Файли

| Файл | Що це |
| --- | --- |
| `tools/watercolorize.py` | перетворює будь-який піксель-арт PNG на дві текстури: `_watercolor` і `_sketch` |
| `example/comet.png` | приклад вихідного піксель-арту (16×8) |
| `example/comet_watercolor.png` | готова картинка аквареллю |
| `example/comet_sketch.png` | та сама картинка олівцевим ескізом |
| `textures/paper_512_seamless.png` | безшовний папір, якщо полотно більше за картинку |

## Як згенерувати текстури для нової картинки

```
pip install pillow numpy scipy
python tools/watercolorize.py my_picture.png --px 32 --out Build/
```

`--px` — скільки пікселів текстури на один піксель арту (24–32 для телефона). Прозорі пікселі — порожній папір. Кожен непрозорий колір — окрема зона фарби. `--seed` змінює малюнок «плям», тож можна підібрати найкрасивіший варіант.

## Як показувати в грі (прогрес)

1. На полотні лежать дві текстури однакового розміру: `sketch` (знизу) і `watercolor` (зверху).
2. Маска прогресу — маленька текстура розміром з піксель-арт (наприклад, 16×8), 1 = зафарбовано, 0 = ні. Фільтр Bilinear, щоб край був м'який.
3. Шейдер: `color = lerp(sketch, watercolor, smoothstep(0.35, 0.65, mask + noise * 0.15))` — шум робить край проявлення «акварельним», а не квадратним.
4. Коли зона заповнюється, її пікселі в масці плавно анімуються 0 → 1 (0.4–0.6 с).

## Кольори й папір

- Папір `#ece2cc` із зерном; полотно всередині панелі K1Candy з кутами 14 px і тонкою темною рамкою.
- Олівець ескізу `#5d5670`, 45% непрозорості.
- Фарба кладеться від світлих кольорів до темних, 82% непрозорості, краї плям темніші (як у справжньої акварелі).
