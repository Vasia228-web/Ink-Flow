# Ink Flow — стилі K1Candy + P2Watercolor

Два обрані стилі, готові до перенесення в Unity.

- **K1Candy/** — глянцеві блоки фігур і поле з квадратними лунками.
- **P2Watercolor/** — картинка, що домальовується аквареллю на папері.
- **tokens.json** — усі кольори, відступи й радіуси дизайн-системи.


Усі PNG мають прозорий фон (крім паперу й прикладів акварелі).
