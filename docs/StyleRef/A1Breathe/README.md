# Ink Flow — тривога поля A1Breathe

- **SPEC.md** — шари, рівні, параметри анімації, кольори.
- **sprites/** — зовнішнє й внутрішнє сяйво для двох рівнів і тонка рамка (864×864, прозорий фон).
- **preview/** — анімація GIF, живий HTML, кадри піку й мінімуму, приклад поля.

Стара червона рамка, що мигає, замінюється повністю.
