# Формат піксельних картинок

Кожна картинка гри — один текстовий файл у `Assets/_Pictures/<тема>/<id>.txt`. Його читає `PixelPicture.Parse` (Core), тест `PictureLibraryTests` перевіряє всі файли проти таблиці рідкості, а `Ink Flow → Setup → Refresh Picture Library` збирає їх у `Assets/_ScriptableObjects/Pictures/PictureLibrary.asset`.

```
id: fox
name: ЛИСИЧКА
theme: animals
rarity: uncommon
colors: K=1 O=9 W=4 U=27
outline: K
grid:
....KKKK....
...KOOOOK...
..KOWOOWOK..
```

## Заголовок

| Ключ | Значення |
|---|---|
| `id` | латиниця й підкреслення; це ідентифікатор у збереженні (колекція, незавершена, розміщення на планетах). Змінювати після релізу не можна. Якщо ключа немає — береться назва файлу. |
| `name` | напис на екрані, ВЕЛИКИМИ, українською |
| `theme` | ідентифікатор теми; людська назва — у `ThemeNames` (Core). Нова тема без назви показується своїм id, не падає |
| `rarity` | `common` · `uncommon` · `rare` · `epic` · `legendary` · `cosmic` |
| `colors` | пари «літера=індекс майстер-палітри» через пробіл; будь-які літери, `.` зайнято під порожнє |
| `outline` | літера контурного кольору з `colors` |
| `grid:` | далі рядки сітки зверху вниз, усі однакової ширини; рядки, що починаються з `#`, і порожні — пропускаються |

Рядки `# коментар` дозволені будь-де до `grid:`.

## Майстер-палітра (§3 майстер-доку)

Індекси 1–30, 0 — порожньо. **1–3 — контурні** (чорнило `#1B1730`, какао `#3A2C2C`, глибокий синій `#26305A`): ними малюється лише контур, у заливці їх бути не може. **4–30 — ігрові**: кожен читається на фоні поля `#14112A` з контрастом WCAG ≥ 4 (тест `MasterPaletteTests`). Повна таблиця — `Core/Config/MasterPalette.cs`; літери, якими користується авторський скрипт, — `Tools/pictures/author.py` (`LEGEND`).

## Правила (тримає тест)

| Рідкість | Сітка файлу, не більше | Ігрових кольорів | Вага випадіння |
|---|---|---|---|
| common | 14 | 2–3 | 45 |
| uncommon | 14 | 3 | 25 |
| rare | 16 | 3–4 | 15 |
| epic | 18 | 4–5 | 9 |
| legendary | 20 | 5–6 | 5 |
| cosmic | 22 | 6–8 | 1 |

- **Сітка файлу = сітка §6 майстер-доку + контурне кільце** по одному пікселю з кожного боку (12 → 14, 20 → 22). Числа живуть у `BalanceConfig.rarityGridSizes`.
- Картинка **не мусить бути квадратною**: в'юха вписує її в квадрат, зберігаючи пропорції. Менша сторона — не менше 6.
- Контур обов'язковий: без нього форми не видно до першої краплі. Заливки має бути більше, ніж половина контуру.
- Кольори заливки сортуються за кількістю пікселів: перший — головний колір картинки; він же перший у лотку.
- **Порядок проявлення** рахує Core (`RevealOrder`): обхід у ширину від нижнього центрального пікселя заливки, спершу вгору; відокремлені контуром області (око, пляма) — з найближчого до вже проявлених. Автор на порядок не впливає.

## Авторський скрипт

`python3 Tools/pictures/author.py` — усі картинки описані компактно (лише те, що видно), скрипт сам домальовує зовнішній контур, обрізає порожні поля, перевіряє таблицю вище й пише файли. `python3 Tools/pictures/contact_sheet.py` — контактний аркуш `docs/pictures-contact-sheet.png` для перегляду оком (рамка — колір рідкості).

Нова картинка = блок `pic(...)` в `author.py` → обидва скрипти → `Refresh Picture Library` → тест `PictureLibraryTests` зелений.
