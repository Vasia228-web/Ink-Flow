# Контрольна точка

1. **Перевірки** — делегуй помічнику `checks-runner` (haiku): check-compile, headless-тести, три чекери; якщо редактор відкритий — ще EditMode-тести й помилки консолі через `python3 Tools/unity-mcp.py`. Червоне — виправ і повтори.
2. **Перезбери й зніми** — скіл `unity-rebuild` (збирачі `Build … Screen` → `Build Main Scene`, знімки). Знімки стану кроку — у `docs/screenshots/meta/` або `docs/screenshots/`; автоперевірка `UiAudit` і бюджет викликів ≤ 35 мають бути зелені (екран — у `MetaScreenshots.AuditEnforced`).
3. **Звір із макетами** — помічник `screenshot-reviewer` (sonnet): пари «знімок 402×874 і 375×667 ↔ `docs/StyleRef/U1Glaze/preview/…`». Висока й середня важливість — виправ і переконайся знову.
4. **Ревізія** (крок U1Glaze): 3–5 лінз (коректність, розкладка/переповнення, продуктивність і щокадрові дотики, навігація й стан, відповідність макету) × скептик, що перевіряє знахідку по коду. Підтверджене — виправ.
5. **Статус** — помічник `docs-keeper`: «Статус» у CLAUDE.md, рядок статусу в промті, `docs/screens.md` для зміненого екрана, рішення — у `docs/implementation-notes.md`.
6. **Звіт автору** — скіл `author-report`: що зіграти (кроки, де, що має бути видно, що вважати помилкою), рішення, ухвалені без нього, що не вдалося перевірити.
7. **Коміт** — явним `git add` по файлах (нові `.meta` — завжди; перезібрані сцени/префаби — лише свого кроку; `DesignSystem.asset` — якщо змінювались токени кроку). Push — лише після «ок» автора (або коли автор явно дозволив працювати без зупинок).
