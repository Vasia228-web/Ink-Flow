# Старт і закриття задачі

**Старт**
1. Прочитай «Статус» у CLAUDE.md і рядок статусу поточного промту в `prompts/` — продовжуй звідти.
2. `git status --short` і `git log --oneline -3`: що вже закомічено, що висить у робочій копії (перезібрані сцени/префаби автора й `DesignSystem.asset` — не твої, не комітити без слова автора).
3. План — через список задач застосунку; ризиковані кроки — спершу в чат автору як вибір між наслідками.

**Закриття**
1. Перевірки — помічник `checks-runner`; контрольна точка — скіл `checkpoint`.
2. Статуси — помічник `docs-keeper` (CLAUDE.md «Статус», рядок у промті, docs).
3. Коміт: `git add` по файлах (нові `.meta` — завжди), повідомлення імперативом українською з рядком співавторства. Push: `git push origin main` (у `main` немає upstream) — лише після «ок» автора.
4. Нагадай автору забрати виконаний промт у `../prompts-archive/` (сам не переміщуй).
