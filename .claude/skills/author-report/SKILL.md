# Звіт для автора

Зміст і тон — за глобальним скілом **beginner-to-pro** (`~/.claude/skills/beginner-to-pro/SKILL.md`): суть → аналогія → як працює → як думає професіонал → що перевірити. Кожен термін пояснити при першій появі. Автор — не програміст: перевіряє вигляд, гру й відповідність плану, не код.

Форма:
- Файл `../reports/YYYY-MM-DD-<тема>.html` (поза git), мова українська, темна тема як у попередніх звітах (`../reports/2026-10-21-claude-md-refresh-session2.html` — візьми звідти `<style>`).
- Порядок розділів: «Про що це простими словами» → «Що перевірити тобі» (кроки: де, що натиснути, що має бути видно, що вважати помилкою) → «Рішення, які я ухвалив за тебе» (кожне — що обрав, чому, як змінити) → питання (вибір між наслідками з рекомендацією, ≤ 3) → тест 8–10 питань про рішення й поведінку гри з відповідями в `<details>` → «Ручні кроки» → **технічне згорнуто** в `<details>` наприкінці (коміти, файли, перевірки, що не вдалося перевірити).
- Знімки: `<img>` з відносним шляхом до PNG у репо або «до/після» поруч, якщо вони є.
- Перевір HTML на збалансовані теги; надішли файл автору.
